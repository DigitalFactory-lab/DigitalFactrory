# Digital Factory — L’histoire d’un pari

Présentation immersive en HTML, CSS et JavaScript.

## Présenter

- Flèche droite ou Espace : avancer.
- Flèche gauche : revenir.
- F : plein écran.
- « Espaces » : lancer la mise en lumière des transformations.

## Hébergement

GitHub Pages : branche `main`, dossier `/ (root)`.
Les fichiers du site sont à la racine ; aucun outil de compilation n’est nécessaire.
